# Configuration

deltoids reads `$XDG_CONFIG_HOME/deltoids/config.toml`, falling back to
`~/.config/deltoids/config.toml`.

## Custom commands

Bind a key in `deltoids tui` to a shell command that runs against the
selected file. Each `[[commands]]` entry maps one `key` to a `command`.
`{{filename}}` expands to the selected file's absolute path, shell-quoted
so paths with spaces work.

```toml
# Background (default): dispatches elsewhere and returns immediately.
# The TUI never touches the terminal, so there is no flicker.
[[commands]]
key = "e"
command = "dev tmux edit {{filename}}"
description = "edit file in a tmux pane"

# Subprocess: takes over the terminal for an inline editor. The TUI
# suspends, hands the terminal to the child, then restores and repaints.
[[commands]]
key = "E"
command = "nvim {{filename}}"
subprocess = true
description = "edit file inline in neovim"
```

`command` is a shell line (run via `sh -c`), not an argv. Custom keys
work against the current selection.

## Language servers

Press `Enter` on a diff line in `deltoids tui` to go to the definition of
the underlined symbol, and `r` to list a function's callers (`w` / `b`
pick another symbol on the line; `Ctrl+o` goes back). On a definition,
`Enter` lists its callers instead. A language server
answers. deltoids starts it as soon as a file in its language shows in
the diff pane and stops it on quit. The diff pane's top border names the
file under the cursor and, at the right, its language and the server's
state: `Rust ●` ready, a spinner (with a percentage when the server
reports one) while it starts or indexes, `✕` when it failed, nothing
when there is no server.

The server reads the files on disk, so navigation works on every line of
the working tree, and on the lines of a commit or branch that have not
changed since (deltoids follows them when lines above moved).
Answers inside the diff move the cursor there; a line outside the shown
hunks opens its hunk, and a file the diff does not touch opens as a
*visited* file, marked `○` in the sidebar. A visited file goes away when
`Ctrl+o` goes back past it, or when the diff holds other files (after a
commit, for example).

deltoids looks for these servers on `PATH`:

| Language | Server |
| --- | --- |
| Rust | `rust-analyzer` |
| Go | `gopls` |
| TypeScript, TSX, JavaScript | `typescript-language-server --stdio` |
| Python | `pyright-langserver --stdio` |
| C, C++ | `clangd` |
| Ruby | `ruby-lsp` |
| Lua | `lua-language-server` |
| Bash | `bash-language-server start` |
| Java | `jdtls` |
| Kotlin | `kotlin-language-server` |

A `[lsp.<language>]` table replaces a server or turns it off:

```toml
[lsp.python]
command = ["basedpyright-langserver", "--stdio"]

[lsp.go]
enabled = false
```

<Note>
  `subprocess` defaults to `false`. Background commands must return
  quickly and must not write to the terminal (their output is
  discarded). Set `subprocess = true` only for a command that takes
  over the screen, such as an inline editor.
</Note>

Custom keys cannot override the built-in bindings (`q`, `[`, `]`, `<`,
`>`, `?`) but can shadow a mode's own keys. Press `?` in the TUI to see
the configured bindings in the help popup.
